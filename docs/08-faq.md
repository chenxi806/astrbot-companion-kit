# FAQ

## 需要向量数据库吗？

不需要。核心系统只用纯文本。

可选的语义查重可以用 `bge-m3` 之类的 embedding API，但不是运行必需。

## 会改我的人格吗？

不会。插件只注入额外内容，不修改 AstrBot 的 persona。

人格是你自己维护的，模式细节放在世界书和语料文件里。

## 支持群聊吗？

默认只对私聊生效（`scope: private`）。

群聊里 @ 她的消息也会触发命令，但注入默认关闭。需要的话把 `scope` 改成 `all`。

## 记忆存在哪？

全部在 `memory_dir` 里：

```
card/ voice_pool/ modes/ raw/
```

纯文本，随时可以看、改、备份、删除。

## 会不会越用越长？

判断卡有预算（1800 字），超了先丢低置信度判断。

示例池每轮只抽 4 条，库再大也不影响单轮长度。

## 为什么命令没反应？

最常见原因：一个函数上叠了多个 `@filter.command`。

AstrBot 会把它们当成“同时满足”，导致永远匹配不上。

正确写法：

```python
@filter.command("good", alias={"好", "存"})
```

## 为什么她文字里冒日语？

检查 `mode_switch` 是否是最新版，以及世界书 `alice` 条目是否还有“全程日语”。

当前规则：**文字中文，只有语音日语**。

## 模式退不出来？

发「退出」「回来」「变回来」。

还不行就删 `memory/modes/state.json`，下次请求会当成没在模式里。

## 可以只要判断卡，不要示例池吗？

可以。只装 `memory_card` + `card_review`，不装另外三个。

反过来只装示例池也可以。

## 数据怎么迁移？

复制整个 `memory_dir` 到新机器，改配置里的路径，重启。

## 支持多个角色吗？

一套 `memory_dir` 对应一个角色。多角色就多份目录、多套配置。

## 费用大概多少？

每次提取是一次普通模型调用，一周一次；注入是固定几百到两千 token。

按常见价格，一个月通常不到一杯奶茶钱。具体看你的 Provider。

## 为什么没有自动 TTS？

TTS 和角色绑定太深（音色、模型、路径），不适合放进通用仓库。

`/艾莉丝` 语音可以接你已有的 TTS 插件。
