# 示例池

示例池回答一个问题：**她说话是什么样子？**

它不管内容，只管语气、节奏、口癖。

## 两层结构

```
库（不限量）         所有 /good 过的句子
上场名单（24~60）    每轮从里面按权重抽 4 条
```

**上限只作用在上场名单。** 库再大也不会删你喜欢的句子。

## 记录

```json
{
  "id": "e251028...",
  "text": "过来。（拍了拍身边）先坐会儿。",
  "scene": "累",
  "likes": 3,
  "picked": 12,
  "status": "active",
  "score": 0.62
}
```

- `likes`: 你 `/good` 过几次
- `picked`: 被抽中过几次
- `status`: `active` / `archived`
- `score`: 权重，抽样时用

## 采集

| 命令 | 作用 |
|---|---|
| `/good` / `/存` | 收她上一句；同一句只累计次数 |
| `/bad` / `/差` | 标记不喜欢，不进池 |
| `/pool` | 看条数、场景分布 |

## 抽样

每轮从 `active` 里按权重抽 4 条：

```
权重 = 0.2 + score × 2
     + log(1 + likes) × 0.3
     + log(1 + picked) × 0.2
     + 场景匹配 ×2
     - 最近用过
```

抽中后 `picked +1`，分数自动更新。

## 审查

### 周审查（周日 20:30）

- 重复：相似度 ≥0.92
- 单场景超过 8 条

命令：`/池审`、`/池通过 1,3`、`/池驳回 2`

### 月审查（每月 1 号 21:00）

在周审查基础上，多查“从没抽中且分低”。

命令：`/池月审`、`/池月通过 1,3`

## 归档不是删除

审查只把 `status` 改成 `archived`，数据还在 `examples.jsonl` 里。

要恢复，把 `archived` 改回 `active` 即可。

## 模式隔离

角色模式中的 `/good`：

- 场景标成 `模式:alice` 或 `模式:maid`
- 默认 `archived`，不进日常抽样

避免角色扮演的日语/傲娇语气污染日常。
