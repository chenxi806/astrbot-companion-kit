# 配置手册

所有配置文件都在 `<AstrBot>/data/config/astrbot_plugin_xxx_config.json`。
改完必须重启（`memory_dir`、`card_path` 这类路径项除外——它们每次请求都会读）。

---

## growth_card

| 项 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 总开关 |
| `card_path` | 空 | 判断卡文件，一般填 `<memory_dir>/card.companion.txt` |
| `memory_dir` | 空 | 记忆目录；留空则用 `<AstrBot data>/companion_memory` |
| `admin_only` | `true` | `/card` 的写操作只给主人 |
| `owner_id` | 空 | 主人 QQ 号；留空则私聊都认 |
| `scope` | `private` | `private` 只在私聊注入；`all` 群聊也注入（不建议） |
| `allowed_umos` | `[]` | 只对这些会话生效，留空表示所有私聊 |
| `record_raw` | `true` | 是否把每轮问答写进 `raw/` |
| `raw_dir` | 空 | 留空则用 `<memory_dir>/raw` |

**命令**：`/card`、`/card reload`、`/card log 内容`、`/card review`

## lorebook

| 项 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 总开关 |
| `lore_path` | 空 | 条目文件；留空则 `<memory_dir>/lorebook.json` |
| `max_entries` | `3` | 每轮最多注入几条；建议 2~4 |
| `scope` | `private` | `private` 只私聊 |
| `allowed_umos` | `[]` | 只对这些会话生效 |

**条目字段**：

```json
{
  "id": "maid",
  "label": "女仆形态",
  "keys": ["女仆", "撒娇", "吾主"],
  "probability": 0.3,
  "cooldown_minutes": 120,
  "priority": 2,
  "content": "切进女仆形态时……",
  "random_pool": false,
  "group_only": false
}
```

- `keys`：命中任意一个就触发；空数组 + `random_pool: true` 表示不靠关键词，按概率随机出现
- `probability`：0~1，没过就不注入
- `cooldown_minutes`：触发后多久内不再出现
- `priority`：越大越优先，最多取 `max_entries` 条

**命令**：`/lore`、`/lore list`、`/lore test 今天好累`

## galgame（关系阶段）

| 项 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 总开关 |
| `memory_dir` | 空 | 用 `raw/` 算天数和互动条数 |
| `scope` | `private` | 只私聊 |
| `allow_confession` | `false` | 关着时锁在「亲密（恋人未满）」 |

**阶段条件**（写在代码里的常量，改需改 `main.py` 的 `STAGES`）：

| 阶段 | 天数 | 条数 | 共同事件 |
|---|---|---|---|
| 认识 | 0 | 0 | 0 |
| 熟悉 | 3 | 100 | 0 |
| 亲近 | 7 | 300 | 1 |
| 亲密 | 21 | 800 | 3 |

**命令**：`/stage`

## state（心情/精力）

| 项 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 总开关 |
| `memory_dir` | 空 | `whims.json` 默认也在里面 |
| `whims_path` | 空 | 留空则 `<memory_dir>/whims.json` |
| `scope` | `private` | 只私聊 |
| `whim_enabled` | `true` | 是否抛小事 |
| `max_per_day` | `2` | 每天最多几次 whim |
| `min_gap_hours` | `5` | 两次 whim 至少间隔 |

**whim 字段**：

```json
{
  "id": "cat",
  "text": "楼下那只橘猫今天蹲在门口",
  "min_mood": 0.45,
  "min_energy": 0.25,
  "window": ["07:00", "23:00"]
}
```

**命令**：`/state`

## daily_ritual（早晚安）

| 项 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 总开关 |
| `morning_time` | `08:00` | 叫起床 |
| `night_time` | `00:00` | 催睡 |
| `timezone` | `Asia/Shanghai` | 时区 |
| `umo` | 空 | 发送目标；留空自动取最近私聊 |
| `memory_dir` | 空 | 读判断卡和最近对话 |
| `context_messages` | `30` | 参考多少条最近对话 |
| `extra_prompt` | 空 | 追加到生成提示词 |
| `catchup_minutes` | `90` | 重启/休眠错过时间后，在这个窗口内补发；0 关闭 |

**命令**：`/ritual status`、`/ritual test morning`、`/ritual test night`

## weekly_review（复盘）

| 项 | 默认 | 说明 |
|---|---|---|
| `weekday` | `6` | 0=周一 … 6=周日 |
| `time` | `21:00` | 几点跑 |
| `timezone` | `Asia/Shanghai` | 时区 |
| `umo` | 空 | 通知发到哪；留空自动取最近私聊 |
| `owner_id` | 空 | 只认这个号回「同意」；留空则私聊都认 |
| `memory_dir` | 空 | 记忆目录 |
| `volume_trigger` | `50` | 攒够多少条新对话就先跑一次；0 表示只看日期 |
| `decay_enabled` | `true` | 未强化的判断每周 −0.01，最低 0.3 |

**命令**：`/review status`、`/review show`、`/review now`、`/review reject`

## 共用：owner_id 怎么查

在私聊里发一条消息，看日志里的 `unified_msg_origin`：

```
default_<bot_id>:FriendMessage:<user_id>
```

`<bot_id>` 一般是机器人 QQ 号；`owner_id` 要填**你的** QQ 号。
不确定就留空——私聊场景下默认都认。
