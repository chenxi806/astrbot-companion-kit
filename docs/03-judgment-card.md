# 判断卡

判断卡回答一个问题：**她记得关于你的什么？**

## 四类

| 类型 | 例子 | 进卡 | 置信度 | 上限 |
|---|---|---|---|---|
| 事实 | 我周三有课 | ✅ | — | 30 |
| 判断 | 以后别在半夜讲道理 | ✅ | 0.85 起 | 40 |
| 雷区 | 别提前任 | ✅ | 1.0 | 10 |
| 洞察 | 他最近睡得晚 | ❌ | 0.5 起 | 50 |

### 为什么洞察不进卡

洞察是缓冲区。不确定的观察先存着，攒够两条证据才升判断，避免卡里塞满猜测。

## 字段

```json
{
  "id": "j251028143000",
  "type": "judgment",
  "text": "以后别在半夜讲道理",
  "confidence": 0.85,
  "status": "active",
  "source": "user",
  "evidence": [{"date": "10-28", "quote": "原话"}],
  "created": "2026-10-28",
  "updated": "2026-10-28",
  "last_reviewed": "2026-10-28",
  "supersedes": null
}
```

- `status`: `active` / `archived` / `superseded`
- `source`: `user` / `review` / `monthly`
- `evidence`: 每条都有一句原话

## 录入方式

### 自动

```
聊天 → raw/*.jsonl → 每周提取 → pending.json → 你审批
```

### 手动

| 命令 | 写入 |
|---|---|
| `/记 内容` | judgment，0.85 |
| `/事实 内容` | fact |
| `/雷区 内容` | taboo，1.0 |
| `/观察 内容` | insight，0.5 |

手动是“你当场决定”，不需要审批。

## 审批

待审清单带编号：

```
判断卡待审（4 条）：
1. [判断] 累的时候先接住情绪
   原话：我累了别跟我讲道理
2. [事实] 周三有课
3. [雷区] 别提前任
4. [洞察] 最近睡得晚

回「通过」全部写入；「通过 1,3」只写这几条；「驳回 2」不要这条。
```

规则：

- 不回，不生效
- 部分通过，剩下的继续挂着
- 选判断时，它引用的洞察会一起写入

## 去重与合并

- 同类型相似度 ≥0.8 → 不新增，合并证据，置信度 +0.03
- 新旧矛盾 → 旧的 `superseded`，新的写 `supersedes`

## 生命周期

```
每周：置信度 -0.01，最低 0.3
<0.45：标 stale
<0.35 且 90 天没动：归档
30 天没复审：进复盘提醒
```

## 月度报告

每月 1 号 21:00 生成：

1. 合并相似度 ≥0.8 的判断
2. 归档置信度 <0.45 或 60 天没更新的
3. 洞察有 ≥2 条证据 → 升判断

命令：`/月审`、`/月通过 1,3`、`/月驳回 2`。

## 渲染

| 文件 | 内容 | 预算 |
|---|---|---|
| `card.md` | 全部，带证据 | 不限 |
| `card.companion.txt` | 事实 + 判断 + 雷区 | ≤1800 字 |

超预算先丢置信度最低的判断，事实和雷区不丢。空卡不注入。
