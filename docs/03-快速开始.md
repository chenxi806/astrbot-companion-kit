# 快速开始（新手版）

> 目标：30 分钟内让机器人拥有「跨会话记忆」。
> 不需要会写代码，但要会复制粘贴、会用记事本改 JSON。

## 0. 你需要先有的东西

1. **一个能正常聊天的 AstrBot**
   官方文档：<https://docs.astrbot.app/>
   确认你能在私聊里收到机器人回复，再往下做。

2. **AstrBot 的数据目录**
   通常长这样：

   ```
   <AstrBot 安装目录>/data/
   ```

   里面应该有 `config/`、`plugins/`、`plugin_data/` 三个文件夹。
   找不到的话，在 AstrBot 面板「关于」里一般能看到数据目录。

3. **一个文本编辑器**
   VS Code、Notepad++ 都行。不要用 Word，会改坏编码。

## 1. 下载并复制插件

```bash
git clone https://github.com/<your-name>/astrbot-companion-kit.git
```

把 `plugins/` 下**六个文件夹**整体复制到：

```
<AstrBot>/data/plugins/
```

复制完应该是这样：

```
data/plugins/
├── astrbot_plugin_growth_card/
│   ├── main.py
│   ├── metadata.yaml
│   └── _conf_schema.json
├── astrbot_plugin_lorebook/
├── astrbot_plugin_galgame/
├── astrbot_plugin_state/
├── astrbot_plugin_daily_ritual/
└── astrbot_plugin_weekly_review/
```

> 只想先试水？只复制 `astrbot_plugin_growth_card` 一个也行，见文末「最小路径」。

## 2. 建记忆目录

在**数据目录**下新建：

```
<AstrBot>/data/companion_memory/
```

把仓库里 `memory-template/` 的内容复制进去：

```
companion_memory/
├── store.json
├── render.py
├── whims.json
├── lorebook.json          # 由 lorebook.example.json 改名
├── events/
└── proposals/
```

Windows 一条命令搞定：

```powershell
.\scripts\init-memory.ps1 -Target "<AstrBot>\data\companion_memory"
```

## 3. 改插件配置

配置文件在 `<AstrBot>/data/config/` 下，文件名是 `astrbot_plugin_xxx_config.json`。
第一次启动前可能还不存在——**先重启一次 AstrBot**，让它自动生成，再改。

### 3.1 六个插件共同的 `memory_dir`

每个插件配置里都有这一项，**必须填同一个绝对路径**：

```json
"memory_dir": "E:\\bot\\instances\\xxx\\core\\data\\companion_memory"
```

> Windows 路径里的反斜杠要写两个：`E:\\bot\\...`。
> 用正斜杠 `E:/bot/...` 也可以，更不容易错。

### 3.2 growth_card 额外要填 `card_path`

```json
"card_path": "E:\\bot\\instances\\xxx\\core\\data\\companion_memory\\card.companion.txt"
```

### 3.3 其他常用项

| 插件 | 项 | 建议值 |
|---|---|---|
| growth_card | `scope` | `private`（只在私聊注入，别把个人信息带进群） |
| lorebook | `max_entries` | `2` 先跑，稳定后改 `3` |
| galgame | `allow_confession` | `false`（先锁在恋人未满） |
| state | `max_per_day` | `2` |
| daily_ritual | `morning_time` / `night_time` | `08:00` / `00:00` |
| weekly_review | `weekday` / `time` | `6`（周日）/ `21:00` |

完整说明见 [配置手册](04-配置手册.md)。

## 4. 重启 AstrBot

插件不会热加载，必须重启。

重启后看日志（`data/logs/astrbot.log`），搜索 `Loading plugin`，应该能看到六个插件名。没有的话：

- 文件夹名必须和 `metadata.yaml` 里的 `name` 一致
- 文件夹里必须有 `main.py`
- 看日志里有没有 `Failed to load plugin`

## 5. 验证

私聊机器人，依次发：

```
/card
/lore
/stage
/state
/review status
```

预期：

| 命令 | 正常输出 |
|---|---|
| `/card` | 一张判断卡（有事实/判断/雷区） |
| `/lore` | `世界书：3 条，最多注入 2 条` |
| `/stage` | `阶段：认识` + 进度 |
| `/state` | `心情：平常` + 精力 |
| `/review status` | 下次复盘时间 |

全部通过，基础就跑起来了。

## 6. 第一次复盘

```
/review now
```

会做三件事：生成提案 → 私聊通知你 → 等你回「同意」。
如果你没收到通知，但命令回了「跑完了」，去 `companion_memory/proposals/` 看文件——通知可能被平台限流。

回复「同意」后：

- `store.json` 多出洞察/判断
- `card.companion.txt` 更新
- 下一轮对话自动用新卡

## 7. 最小路径（只装一个）

如果六个太多，先只做这一步：

1. 复制 `astrbot_plugin_growth_card`
2. 建 `companion_memory/`，放 `store.json` + `render.py`
3. 配好 `memory_dir` 和 `card_path`
4. 跑一次 `python render.py`
5. 重启

这样你就有「跨会话记忆」了。世界书、阶段、状态以后再加，互不影响。
