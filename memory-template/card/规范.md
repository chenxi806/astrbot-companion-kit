# 判断卡记录规范

## 四类

| 类型 | 记什么 | 置信度 | 上限 | 进卡 |
|---|---|---|---|---|
| fact 事实 | 生日、课表、忌口 | 不需要 | 30 | 是 |
| judgment 判断 | 以后怎么做的规则 | 0~1 | 动态 24~40 | 是 |
| taboo 雷区 | 绝对不碰的底线 | 1.0 | 10 | 是 |
| insight 洞察 | 还不确定的观察 | 0~1 | 50 | 否 |

## 字段

- `id`：类型首字母 + 日期序号
- `text`：一句话，≤120 字
- `confidence`：判断和洞察有
- `status`：active / superseded / archived
- `source`：user / chat / review
- `evidence`：数组，每项 `{date, quote}`
- `created` / `updated` / `last_reviewed`
- `supersedes`：被谁取代

## 录入

| 入口 | 写什么 | 置信度 |
|---|---|---|
| `/记` | 判断 | 0.85 |
| `/事实` | 事实 | — |
| `/雷区` | 雷区 | 1.0 |
| 聊天推断 | 只写洞察 | 0.5 起 |
| 复盘 | 提案 | — |

硬规则：

1. 推断不能直接进判断，先进洞察
2. 洞察要两条证据才能升判断
3. 事实只写明确说过的，不猜

## 去重与冲突

- 同类型相似度 ≥0.82 → 合并，证据并集，置信度取高 +0.03
- 新旧矛盾 → 旧 `superseded`，新写 `supersedes`

## 生命周期

- 每周置信度 -0.01，最低 0.3
- <0.45 标 stale
- <0.35 且 90 天没动 → 归档
- 30 天没复审 → 进复盘提醒

## 渲染

- `card.md`：全部，带证据
- `card.companion.txt`：事实 + 判断 + 雷区，≤1800 字
- 超预算先丢低置信度判断，事实和雷区不丢

## 审批

- 每周提案带编号
- `同意 1,3`、`驳回 2`
- 未处理的继续挂着
